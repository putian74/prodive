# Parameter-sensitivity analyses

This module contains scripts for evaluating the sensitivity of ProDive results to fragment length, first- and second-stage thresholds, path-level cutoffs, third-stage score thresholds, and large-dataset structural-context sampling.

## Inputs

| Input | Source |
|---|---|
| Pfam seed HHM/STO/FAS files | `$PRODIVE_DATA_ROOT/shared/PfamA_seed/` |
| Packed HHM databases and pair-list outputs | Generated by the main ProDive pipeline or released precomputed resources |
| Raw C++/CUDA KL outputs | Output of the ProDive C++/CUDA computation stage |
| Pfam-Pfam ProDive result and score subsets | `$PRODIVE_DATA_ROOT/shared/` or `$PRODIVE_PRECOMPUTED_ROOT/` |
| Pfam structure runtime directory | `$PRODIVE_PFAM_RUNTIME_ROOT` for structure-dependent sampling |

## Fragment-length sensitivity workflow

| Step | Script | Main input | Main output |
|---:|---|---|---|
| 1 | `scripts/fragment_length/01_pack_fixed_length_hhm_fragments.py` | Pfam HHM files | Fixed-length packed fragment databases |
| 2 | `scripts/fragment_length/02_generate_multi_fragment_packed_db.sh` | Packed fragment databases | Multi-length packed database resources |
| 3 | `scripts/fragment_length/03_generate_fixed_pairlist.py` | Family mapping and length settings | Pair lists for fragment-length scans |
| 4 | `scripts/fragment_length/04_compute_background_kl_for_fragment_lengths.py` | Packed databases | Background KL summaries by fragment length |
| 5 | `scripts/fragment_length/05_run_pairlist_all_fragment_lengths.sh` | Pair lists and packed databases | Raw pair-list KL outputs |
| 6 | `scripts/fragment_length/06_analyze_fragment_length_sensitivity.py` | Raw outputs and background summaries | Fragment-length sensitivity tables |
| 7 | `scripts/fragment_length/07_plot_fragment_length_sensitivity.py` | Sensitivity tables | Fragment-length sensitivity figures |

## Threshold-scan workflow

| Step | Script | Main input | Main output |
|---:|---|---|---|
| 1 | `scripts/threshold_scan/01_convert_raw_cpp_to_sparse_npz_monitor.py` | Raw C++/CUDA outputs | Sparse NPZ files |
| 2 | `scripts/threshold_scan/02_apply_first_second_threshold_grid.py` | Sparse NPZ files and threshold grid | Filtered threshold-combination outputs |
| 3 | `scripts/threshold_scan/03_extract_family_sets_by_threshold.py` | Filtered outputs | Family-coverage tables by threshold |
| 4 | `scripts/threshold_scan/04_scan_path_threshold_grid.py` | Threshold-combination outputs | Path-threshold scan summaries |
| 5 | `scripts/threshold_scan/05_collect_third_score_thresholds.py` | Path-threshold scan results | Third-threshold summary tables |
| 6 | `scripts/threshold_scan/06_plot_global_threshold_grid.py` | Threshold summary tables | Threshold-grid figures |
| 7 | `scripts/threshold_scan/07_logistic_second_derivative_extrema.py` | Threshold curves | Second-derivative extrema tables and plots |

## Large-dataset structural-context sampling

| Step | Script | Main input | Main output |
|---:|---|---|---|
| 1 | `scripts/large_structure_validation/01_sample_filtered_paths.py` | Filtered ProDive result table | Sampled path subsets |
| 2 | `scripts/large_structure_validation/02_compute_sample_ss_rsa.py` | Sampled subsets and Pfam runtime directory | SS/RSA summaries for sampled large-dataset subsets |

Run templates:

```bash
cd prodive_parameter_sensitivity
bash run_templates/run_fragment_length_sensitivity_pipeline.sh
bash run_templates/run_threshold_scan_pipeline.sh
bash run_templates/run_parameter_threshold_extra.sh
bash run_templates/run_large_structure_validation_sample.sh
```

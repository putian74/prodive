# KL filtering, path extraction, and final rescoring

This directory contains the three post-CUDA stages that convert raw C++/CUDA KL matrices into final ProDive path calls.

The scripts are intentionally kept in one directory because they must be executed in this order:

```text
01_filter_cpp_kl_results.py
    C++ KL matrices -> sparse filtered pickle files

02_build_paths_from_filtered_pk.py
    filtered pickle files -> clean diagonal paths

03_rescore_paths_by_coverage.py
    clean paths + coverage tables -> final rescored paths
```

## Requirements

```bash
python3 -m pip install -r src/path_extraction/requirements.txt
```

## Step 1: filter C++ KL matrices

Script:

```text
scripts/01_filter_cpp_kl_results.py
```

Inputs:

```text
kl_output/                         C++/CUDA output directory containing kl_<i>_<j>.npy files
hhm_mapping.txt                    record-name to numeric-ID mapping from preprocessing
background_kl_fragment_6.json       per-record background/window-information arrays
```

Command:

```bash
python3 src/path_extraction/scripts/01_filter_cpp_kl_results.py \
  --input-dir /path/to/kl_output \
  --output-dir /path/to/filtered_pk \
  --mapping-file /path/to/hhm_mapping.txt \
  --background-json /path/to/background_kl_fragment_6.json \
  --fragment 6 \
  --raw-threshold 2.0 \
  --filter-threshold 13.0 \
  --epsilon 0.0001
```

Filtering rule:

```text
raw4 = round(raw_score, 4)
keep raw4 < raw_threshold
linear = (query_background[row] + target_background[col]) / (raw4 + epsilon) * (3 * fragment + 2)
keep linear >= filter_threshold
```

Default parameters:

```text
fragment = 6
raw_threshold = 2.0
filter_threshold = 13.0
epsilon = 0.0001
background_dtype = float32
```

The default raw-score rule is strict `< 2.0`. Use `--raw-threshold-inclusive` only when reproducing an earlier pipeline version that intentionally used `<=`.

Outputs:

```text
filtered_pk/
├── kl_<query_record_name>_filtered.pk
└── filter_cpp_kl_run_summary.json
```

The pickle structure is:

```python
{
    target_record_name: {
        query_window_start_1based: {
            target_window_start_1based: round(linear, 4)
        }
    }
}
```

C++ matrices use 0-based NumPy coordinates. The output pickle uses 1-based window-start coordinates for compatibility with path extraction.

## Step 2: build diagonal paths

Script:

```text
scripts/02_build_paths_from_filtered_pk.py
```

Inputs:

```text
filtered_pk/                 directory containing kl_<query_record_name>_filtered.pk files
hhm_mapping.txt              optional mapping file used to recover sanitized record names
```

Command:

```bash
python3 src/path_extraction/scripts/02_build_paths_from_filtered_pk.py \
  --input-dir /path/to/filtered_pk \
  --output-dir /path/to/path_results \
  --mapping-file /path/to/hhm_mapping.txt \
  --fragment 6 \
  --min-path-points 5 \
  --workers 20
```

Outputs:

```text
path_results/
├── global_high_score_summary.csv
├── global_UNCL_overlap_report.csv
├── global_jump_gap_report.csv
└── path_building_summary.json
```

`global_high_score_summary.csv` is the clean one-to-one path table and is the normal input for final rescoring.

Main parameters:

```text
--fragment                  HHM fragment/window length. Default: 6.
--min-path-points            minimum number of linked window-pair points required to keep a path. Default: 5.
--overlap-iou-threshold      main-axis IoU threshold for clustering overlapping paths. Default: 0.1.
--top-n                      optional maximum number of clean paths retained per comparison.
--allowed-list               optional file containing record IDs; a pair is processed if either side is listed.
```

With `--fragment 6` and `--min-path-points 5`, the minimum nominal segment span is 10 state positions.

## Step 3: final coverage-based rescoring

Script:

```text
scripts/03_rescore_paths_by_coverage.py
```

Inputs:

```text
global_high_score_summary.csv       clean path table from Step 2
coverage_tables/                    directory containing *_coverage.csv files
```

Coverage tables should be generated by:

```text
data_preparation/scripts/04_generate_hhm_coverage.py
```

Expected coverage CSV columns:

```text
Match_State,MSA_Column,Residue_Count,Total_Seqs,Completeness_Percent
```

Command:

```bash
python3 src/path_extraction/scripts/03_rescore_paths_by_coverage.py \
  --input-csv /path/to/path_results/global_high_score_summary.csv \
  --coverage-dir /path/to/coverage_tables \
  --output-csv /path/to/final_paths.csv \
  --rescored-all-csv /path/to/all_paths_rescored.csv \
  --coverage-threshold 0.85 \
  --score-threshold 1.2 \
  --score-distribution-png /path/to/score_distribution_before_after.png
```

Score definition:

```text
weight = (Coverage_Main + Coverage_Sub) / 2
Rescored_Score = log10(Avg_Similarity * weight^2)
```

Rows are retained when:

```text
Coverage_Main >= 0.85
Coverage_Sub  >= 0.85
Rescored_Score > 1.2
```

Outputs:

```text
final_paths.csv                         final retained path table
final_paths.summary.json                aggregate run summary
all_paths_rescored.csv                  optional all-row rescored table
score_distribution_before_after.png     optional diagnostic plot
```

`--rescored-all-csv` is optional and saves all rows after rescoring but before final filtering.
